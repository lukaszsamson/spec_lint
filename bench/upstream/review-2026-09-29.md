Adversarial caveat: the draft/comment “accepts any value” must be scoped to the list branch. `f(false, :ok)` raises `ArgumentError`; the function does not accept every Cartesian pair of arguments. That does not invalidate the successful witness or false call warning. Controls: direct `into: []` accepts `:ok`; direct `into: ""` rejects it. A correlated choice with `target = if flag, do: [], else: ""` and `value = if flag, do: :ok, else: "ok"` returns `[:ok]`/`"ok"`, confirming both intended successful paths.

For the second reproducer, the first `b/1` arrow is identical in both modules. The fallback arrow changes from `not empty_list() and not non_empty_list(term(), term()) -> dynamic(not ...)` without `a/1` to `term() -> dynamic()` with `a([x | _])`. This is an overapproximation and remains sound.
